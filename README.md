# Advanced RAG with DBT and Mixed Vector/Graph Retrieval

## 🎯 Purpose

We are building an AI-driven retrieval layer where an LLM orchestrator sits in front of both a **vector database** and a **graph database**. At query time, the LLM decides whether to query the vector store (semantic search) or traverse the graph store (relationship search), then fuses the results into precise natural-language answers.

This project automates:

- Schema & sample-data extraction from MSSQL
- DBT model scaffolding (views, docs, lineage)
- Preparation of raw metadata for ingestion

## ⚙️ Prerequisites

1. **Python 3.10+** & virtualenv or Conda
2. **ODBC Driver 18 for SQL Server** (unixODBC)
3. **DBT 1.10.3** + `dbt-sqlserver` plugin
4. **Write permissions** on your MSSQL instance

## 🛠 External Configuration

### 1. DBT Profiles

Create your DBT profile at `~/.dbt/profiles.yml`:

```yaml
transporters_profile:
  target: dev
  outputs:
    dev:
      type: sqlserver
      driver: "ODBC Driver 18 for SQL Server"
      server: 207.180.243.86
      port: 1433
      database: WideWorldImportersDW
      schema: dbo
      UID: sql-crafter
      PWD: start123
      encryption: True
      trust_cert: True
```

### 2. Raw Metadata & Samples

The extractor (`extract_all.py`) writes `all_tables.json` in its folder. **Copy** that file into:

```
src/dbt_files_outside_project/all_tables.json
```

This allows `generate_dbt_models.py` to read the raw metadata outside the main models directory.

## 🚀 Getting Started

1. **Install dependencies**

   ```bash
   # using pip
   pip install -r requirements.txt

   # or using Conda
   conda env create -f environment.yml
   conda activate rag-poc
   ```
2. **Extract schema & samples**

   ```bash
   python src/extract_all.py
   cp src/all_tables.json src/dbt_files_outside_project/
   ```
3. **Generate DBT models**

   ```bash
   python src/generate_dbt_models.py
   ```
4. **Run DBT**

   ```bash
   dbt run
   dbt docs generate
   ```
5. **Serve documentation**

   ```bash
   dbt docs serve
   # then browse http://127.0.0.1:8080
   ```
